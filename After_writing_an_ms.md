Some things you might want to do after writing a ms:

- Stop editing the manuscript and publish it! Knowing when to sptop is important.
- Make sure you link your data and code to the paper via Zenodo, which will provide a DOI for you. If in a github repo, add the DOI to the repo.
- Make sure you acknowledge the right people, funding and institutions.
- Make a preprint so it's accesible to anyone with no delay.
- Choose a journal wisely. cover letters and suggested reviewers are important.
- When accepted:
  - Create a press release if relevant. Sandra at EBD can help with this and distributed.
  - In any case, tell Sandra, so you appear in EBD al día friday's bulletin. email is outreach@ebd...etc...
  - Brag in social media and tag institutions and co-authors.
